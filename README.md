# Zapmail
## Description
An application designed to automate bulk email campaigns based on data from CSV files. The first team project for CSCE 606 Software Engineering ran using agile methodology and designed to function with JavaScript disabled as per the initial application requirements.

## Deployment
### Details
This project is deployed on heroku via a github actions CI/CD pipeline. All changes are first merged as pull requests to the preprod branch after careful team evaluation and unit testing with Rspec. Afterwards, the pull request may only be merged to the prod branch after the passing of 90% coverage acceptance/validation tests using Cucumber with zero Rubocop offenses in Models, Controllers, Helpers and Tests. Changes are usually merged as pull requests to the prod branch as increments rather than user stories whereas in the preprod branch changes will be merged in by user story. The link to access the project via heroku is provided below for your convenience.
- Zapmail Heroku Application Link: https://zapmail-9fced4208cf0.herokuapp.com/
